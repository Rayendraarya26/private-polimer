## BBKKP Polimer

### Deskripsi
Portal Utama pelanggan BBKKP, dibuat dengan menggunakan framework Laravel dan React Vite

### Instalasi
1. Clone repository ini
2. Copy file `.env.example` menjadi `.env`
3. Setting file `.env` sesuai dengan konfigurasi database
4. Jalankan perintah `php artisan key:generate`
5. Jalankan perintah `php artisan migrate:fresh --seed`
6. Jalankan perintah `composer install`
7. Jalankan perintah `npm install`
8. Jalankan perintah 
   - `php artisan serve`  
   - `npm run dev` untuk develop frontend
